# maxoududu.github.io

Modernized personal website built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

## Build static export

```bash
npm run build
```

The static export is generated in `out/`.
